# FIK Town Hall

Standalone civic participation platform powered by the FIK intelligence system.

## Architecture
- Dedicated application, data store, authentication and deployment
- FIK gateway is an external, permission-controlled intelligence service
- Human approval required before any external civic submission
- No Snout or PCNP dependencies or shared credentials

## Status
Repository initialized. Application source from the v0.3.1 deployment package is being migrated separately. No live deployment or database is connected yet.
